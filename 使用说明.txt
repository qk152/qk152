养老政策一站通 · 使用说明
======================================================================


【三种访问方式】

方式一 · 公网访问
  适用：评委用手机流量扫，不受现场 Wi-Fi 限制
  赛前准备：
    1. 把 index.html、images/、data/ 上传到 GitHub 仓库
    2. Settings → Pages → Source 选 main 分支 → Save
    3. 得到 https://用户名.github.io/仓库名/ 网址
    4. 运行 生成二维码.py，输入这个网址，生成二维码
    5. 把二维码图片放进 PPT 最后一页
  现场：评委扫码即开


方式二 · 本地启动（最可靠）
  适用：完全封闭无网，U 盘双击直接打开
  赛前准备：
    1. 把 启动养老政策站.bat 和 index.html 放在同一个文件夹
    2. 一起拷进 U 盘
  现场：插 U 盘 → 双击 bat → 浏览器自动打开


方式三 · 局域网访问
  适用：现场有 Wi-Fi 或手机热点，电脑手机同网
  赛前准备：
    1. 在有网电脑上 pip install qrcode[pil] pyinstaller
    2. 用 pyinstaller 把 server.py 打包成"启动局域网服务.exe"
    3. 把 exe 和 生成二维码.py 一起放进 U 盘
  现场：
    1. 电脑连手机热点
    2. 双击 启动局域网服务.exe
    3. 看命令行窗口里打印的手机访问 URL
    4. 用 生成二维码.py 生成这个 URL 的二维码给评委扫


【U 盘最终目录结构】

养老政策一站通/
  index.html
  启动养老政策站.bat
  启动局域网服务.bat（可选）
  server.py（可选）
  生成二维码.py（可选）
  使用说明.txt
  images/
  data/


【现场应急方案】

如果二维码扫不开：
  → 直接用方式二，双击 启动养老政策站.bat

如果局域网起不来：
  → 检查 Windows 防火墙是否放行 8000 端口
  → 换个端口，改 server.py 里 PORT = 8000 为 8001

如果 PPT 里的二维码打不开：
  → 检查二维码生成时用的 URL 是不是最新的

附：文件用途速查

  启动养老政策站.bat   双击用默认浏览器打开同目录的 index.html
                       不需要网络、不需要 Python、不需要后台服务
                       用 %~dp0 定位自身目录，U 盘插到哪台电脑、是哪个盘符都能用

  server.py            本机起 HTTP 服务，监听 0.0.0.0:8000
                       手机连同一个 Wi-Fi 后，用打印出来的地址访问
                       纯 Python 标准库，不需要装任何第三方库

  启动局域网服务.bat   没打包 exe 时，双击这个直接运行 server.py

  生成二维码.py        输入一个网址，生成 500x500 的二维码图片 qrcode.png
                       前景墨绿 #2D4A3E、背景白色，可直接放进 PPT 或打印
                       需要先安装：pip install qrcode[pil]

  index.html           网站本体，单文件、纯静态、不依赖外网
